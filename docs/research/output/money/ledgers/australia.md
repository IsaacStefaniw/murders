# Australian personal-finance source ledger

Compiled 8 September 2026. Rules applied: no product, platform, fund, ticker or return figure is recorded for app use; threshold amounts and rates are recorded only with the page and financial year and are flagged "changes yearly". Grades are for practices built on the item (A meta-analysis/broad agreement, B trials or very large cohorts, C smaller/mixed, D rules-of-the-system or expert practice, E unproven). "Facts about rules" default to D because they are rules, not outcome evidence.

Verification status legend:
- VERIFIED = page opened and read.
- UNVERIFIED (403) = ato.gov.au returns HTTP 403 to automated fetch; URL is the ATO page returned by search and the figure is corroborated by the search-engine snippet of that ATO page, but the page itself was not opened. Treat as needing a human click-through before the app ships the figure.
