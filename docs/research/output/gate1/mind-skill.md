Ten Percent Happier, roster-guest rows on the big venues, tim.blog and
hubermanlab.com references far above raw row count — and the literature sweep
(inlet 2) carries proportionally more of this round than it did for Work.

## Addendum to F — a rule breach found in passing, outside these two pillars

Checking the Peterson position across the whole library rather than only the
mind and skill slices turned up something the connection round needs to know.

Peterson carries 10 credits in `protocols.ts` and 4 in `protocols.people.ts`.
**Two of them are sole attributions**, which the roster rule forbids:

- `friend-reach-out` — "Reach out, make a plan", pillar **connection**, grade C
- `one-on-one-child` — "One-on-one with each child", pillar **connection**, grade D

Both are outside this gate's scope and neither is proposed for change here. They
are recorded because Gate 1 for the connection pillar runs next and this is
exactly the kind of thing that stays invisible when discovery is done inside one
pillar at a time — which is the whole argument for the restructure. The fix is
cheap in both cases: both practices have obvious independent research lineages
(social-support and parent-child-time literatures respectively) that would give
each card a second, researcher-level name.

Within mind and skill specifically, the rule is satisfied and no expansion is
proposed.
